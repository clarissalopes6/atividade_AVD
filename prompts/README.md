# Prompts

Esta pasta reúne um resumo dos prompts usados no projeto e a declaração de uso de IA. O objetivo é manter o histórico das instruções aplicadas ao trabalho, seguindo o mesmo modelo do repositório-base usado na disciplina.

## Arquivos

- [prompt_dashboard.md](prompt_dashboard.md) — resumo dos prompts simulados usados na criação do dashboard.
- [declaracao-uso-ia.md](declaracao-uso-ia.md) — declaração formal do uso de IA no projeto.

## Como usar

Os prompts aqui registrados servem como referência para:

- documentar a direção da análise;
- registrar a ideia do dashboard e os filtros;
- justificar o uso da IA no processo de desenvolvimento;
- manter um histórico simples e organizado para a entrega final.
