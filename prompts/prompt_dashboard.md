# Prompt de suporte para a criação do dashboard

Crie um dashboard em Streamlit para análise de desempenho escolar com foco em coordenação pedagógica. Inclua:

- painel lateral com seletor de variável quantitativa
- filtro por intervalo de notas para excluir valores fora do intervalo desejado
- duas abas: laboratório de análise e KPIs para gestão
- mapa de calor de correlação
- histograma da variável selecionada
- métricas próprias com 3 a 5 indicadores
- pelo menos 3 visuais adicionais no dashboard 2
- uso de dados anonimizados sem expor student_id em gráficos
- foco em análise real do dataset, sem inventar variáveis
